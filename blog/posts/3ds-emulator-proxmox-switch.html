Playing 3DS games on a Switch, via Proxmox

A 3DS emulator running on my homelab server, played through the Nintendo Switch's web browser.

The Switch can't play 3DS games, but it does have a web browser tucked away, and my homelab runs Proxmox. Put those together and you get 3DS games running on a server in the cupboard and played from the couch on a Switch.

Note: only play games you own, dumped from your own cartridges. This post covers the setup, not where to get games.

How it fits together

There are three pieces: a 3DS emulator running in a container or VM on Proxmox, something that streams the emulator's screen to a web page, and the Switch's browser showing that page.
